# 🐱 Cat Tracking System - Python Edition

## 🚀 High-Performance GPU-beschleunigte Objekterkennung

Das modernste Cat Tracking System mit CUDA-beschleunigter YOLO-Erkennung und präziser Servo-Steuerung.

### ✨ Features
- **🚀 CUDA YOLO:** 30-60+ FPS Real-time Objekterkennung
- **🎯 Auto-Targeting:** Intelligente Freund-Feind-Erkennung
- **🎮 Servo-Steuerung:** Präzise UI-Slider für Pan/Tilt Control  
- **📹 Video-Recording:** Automatische Combat-Aufzeichnung
- **🌐 Dual-Mode:** Local Camera + Network Server/Client

### 🔧 Schnellstart
```bash
# Client (PC mit NVIDIA GPU)
cd client
pip install -r requirements.txt
python gui_client.py

# Server (Raspberry Pi - optional)
cd server  
pip install -r requirements.txt
python camera_server.py
```
